Um jogo da velha interativo com Inteligência Artificial, desenvolvido com **HTML, CSS e JavaScript puro**. O projeto oferece três níveis de dificuldade e modo multiplayer local.

---

## 🎯 Funcionalidades

### 🤖 Modos de Jogo

| Modo | Descrição |
|------|-----------|
| **Vs Computador** | Enfrente a IA com 3 níveis de dificuldade |
| **Multiplayer** | Jogue com um amigo no mesmo computador |

### 🧠 Níveis de Dificuldade

| Nível | Comportamento | Descrição |
|-------|---------------|-----------|
| 😊 **Fácil** | Aleatório | IA faz jogadas aleatórias, perfeito para iniciantes |
| 🧐 **Médio** | 70% Inteligente + 30% Aleatório | IA joga bem mas comete erros ocasionais |
| 😈 **Difícil** | Minimax | IA nunca perde, usa algoritmo de decisão perfeito |

### 🎨 Características

- ✅ **Design Moderno** - Interface com glassmorphism e tema escuro
- ✅ **Responsivo** - Funciona em desktop, tablet e mobile
- ✅ **Placar** - Contabiliza vitórias, derrotas e empates
- ✅ **Feedback Visual** - Animação nas células vencedoras
- ✅ **Modal de Confirmação** - Evita zerar placar acidentalmente
- ✅ **Sem dependências** - Apenas HTML, CSS e JavaScript puro
